# Scenarios

Each scenario must provide a deterministic simulator, action schema, external
oracle, frozen fault schedules, calibration policies, and evaluator-defeat tests.
Read `../docs/11_scenario_boundaries_and_parallel_work_protocol.md` before
changing a scenario. Scenario readiness and evidence never transfer across
these directories.

- `memory_governor/`
