main-study analyses here. Empirical documents must link to raw artifacts and
state their cohort and measurement boundaries explicitly.

- `../RESEARCH_ROADMAP.md`: gate status and research boundary.

development context; its v0.4 status does not control the v0.6 API path.

an execution instruction after the completed v1.0 cohort.
